# packages/ui Tailwind move: isolated screenshots

Each primitive is rendered alone by `tests/visual/ui/harness.tsx`, built with the
app's Vite config so it gets the same Bootstrap + Less + Tailwind stylesheet
(and the generated RTL stylesheet). Chromium, 800x900 viewport, scale 1, reduced
motion, animations disabled. `before/` is origin/main (f3abd46a4), `after/` the
branch `ui-tailwind-primitives`. `diff/` marks differing pixels in red over a
faded copy; any channel difference counts.

Reproduce: `tests/visual/ui/run.sh OUT_DIR` in each checkout, then
`BEFORE_DIR=… AFTER_DIR=… DIFF_DIR=… pnpm exec playwright test -c tests/visual/ui/playwright.config.cts diff`.

rem padding drifts by about 7px in a heading. Spinner rows in that run moved by a
fraction of a pixel because the badge row above them changed height.
