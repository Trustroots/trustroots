## ADDED Requirements

### Requirement: Get Started FAQ

The public FAQ SHALL offer a Get Started category at `/faq/get-started`
with answers and Trustroots Wiki links about using Trustroots, writing a
profile, staying safe and understanding hospitality exchange.

#### Scenario: Visitor browses the Get Started FAQ

- **WHEN** a visitor opens Get Started from the FAQ sidebar
- **THEN** the page displays all four answers and their wiki links
- **AND** the sidebar links to each question on the page

#### Scenario: Visitor searches for newcomer guidance

- **WHEN** a visitor searches the FAQ for text from a Get Started answer
- **THEN** the matching answer appears under Get Started
