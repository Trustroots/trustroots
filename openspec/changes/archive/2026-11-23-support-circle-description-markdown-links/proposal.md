# Support Markdown links in circle descriptions

## Why

Circle administrators need a simple way to add labelled links from the description field.

## What Changes

- Render inline Markdown links to HTTP and HTTPS destinations in the web circle
  description and its editor previews.
- Show the supported syntax next to the description field.
- Preserve existing HTML links, automatic links and formatting.

## Impact

Web circle descriptions and the admin and organiser editors.
