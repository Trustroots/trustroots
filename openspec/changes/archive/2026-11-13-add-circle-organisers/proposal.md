# Add circle organisers

## Why

Members need a way to find the people who help organise a circle.

## What Changes

- Let site administrators manage an optional organiser list on new and existing circles.
- Show eligible organisers as profile links on the signed-in web circle detail page.
- Store assignments by member ID and apply profile visibility when reading the list.

## Impact

Circle detail responses, the existing circle editor, and the web circle detail page.
