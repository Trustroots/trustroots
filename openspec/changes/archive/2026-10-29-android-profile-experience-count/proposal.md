## Why

Members can see the contact count in Android profile tabs but cannot see the number of experiences without opening the tab.

## What Changes

- Show the loaded experience count in the Android profile tab when it is positive, matching the Contacts tab.

## Capabilities

### Modified Capabilities

- `native-android-member-app`: Profile tabs display the available experience count.

## Impact

- Android profile presentation and its UI tests; no API or data migration changes.
