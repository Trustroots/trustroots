# Show meeting availability on mobile profiles

## Why

The web profile shows meeting availability separately from accommodation.
Android and iOS already load the same hosting offer, where the server returns
the member’s meeting preference and volunteering flag.

## What changes

- Show explicit Yes, Maybe and No meeting states on Android and iOS profiles.
- Show the volunteering label on current or tentative hosting offers.
- Reuse the existing mobile offer response and profile access rules.
