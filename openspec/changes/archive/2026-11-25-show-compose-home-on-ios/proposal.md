# Show shared Home in the regular iOS app

## Why

The existing shared Home preview already uses the regular iOS shell and
secure session. Making it the default moves a complete member destination
to Compose and makes it directly available on an iPhone.

## What changes

- Open shared Home when a signed-in member launches the regular iOS app.
- Keep Search, Messages and Menu in the main tab bar, and place Circles in Menu.
- Open profiles from Home using the existing iOS profile navigation.
