## Why

Existing circle descriptions contain addresses such as bare domains that readers cannot click. Assigned organisers need to maintain the name and description of their circles.

## What Changes

- Turn web addresses in circle descriptions into clickable links in the circle page and editor previews.
- Let eligible assigned organisers update the name and description of their visible circles through the circle page.
- Keep circle creation, visibility, images, and organiser assignments under administrator control.

## Impact

The circle API and circle page gain organiser editing. The shared rich text renderer supports web addresses in circle descriptions, including the administrator preview. Existing descriptions and organiser assignments require no data migration.
