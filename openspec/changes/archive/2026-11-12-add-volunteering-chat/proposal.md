## Why

Prospective volunteers need a place to ask questions and talk with other members.

## What Changes

- Add a dedicated Nostr chat to the volunteering page using the same relays and
  identity flow as the Hackers chat.
- Keep the volunteer enquiry and Team Guide links available.

## Capabilities

### New Capabilities

- `volunteering-chat`: A dedicated chat for volunteering discussions.

## Impact

The shell composes the volunteering page with the shared topic chat. No new
server endpoints or credentials are needed.
