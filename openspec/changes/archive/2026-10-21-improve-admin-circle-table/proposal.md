## Why

The circle catalogue centres names, repeats the member-count label on every row and hides descriptions, making comparison difficult.

## What Changes

- Present circle images, left-aligned names, descriptions and numeric membership counts in a table.
- Sort names, descriptions and counts in either direction through accessible column controls.
- Preserve circle selection, editing and hidden-circle indicators.

## Impact

- Admin circle catalogue UI and its client and browser tests.
- No API or permission changes.
