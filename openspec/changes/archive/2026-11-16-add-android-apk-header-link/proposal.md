## Why

Android visitors to the Trustroots website need a simple way to find the signed
Android preview APK.

## What Changes

- Show a small text link below the shared navigation on Android.
- Use the existing latest APK page to resolve the signed preview download.

## Capabilities

### Modified Capabilities

- `site-presentation`: Offer the Android preview download in the shared header.

## Impact

The web shell and core header styles and translations change. Deployment uses
the existing download page and requires no data migration or API changes.
