# Filter public Experiences on member profiles

## Why

Members reading a long list of public Experiences need to find accounts
relevant to a planned meeting or stay. The list can be narrowed using the
interaction and recommendation already recorded for each Experience. This is
part of #3750.

## What changes

- Allow users to combine interaction and recommendation filters and select
  newest or oldest first for the public list.
- Let users toggle the same filters directly from tags on a public card.
- Keep the overall public summary and the owner's awaiting-reply section
  independent of the list filters.
