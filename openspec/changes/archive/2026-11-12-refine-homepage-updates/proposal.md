## Why

Homepage updates need readable links and author attribution. People publishing Nostr events through Trustroots need to know which relays receive them.

## What Changes

- Support inline Markdown links in featured notes and show the author's profile link under Trustroots updates.
- Send new homepage notes only to the Trustroots relay.
- Show configured relay destinations before publication in Trustroots publishing interfaces.

## Capabilities

### Modified Capabilities

- `nostr-integration`: Improve featured note presentation and disclose publication destinations.

## Impact

- Homepage, featured note admin, circle chat, radio and hackerspace publishing.
