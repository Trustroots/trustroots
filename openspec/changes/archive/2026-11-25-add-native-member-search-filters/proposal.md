# Add filtered member search to the native search switch

## Why

Mobile members should be able to search by name, username, location or
tagline from the same entry point they use for map search.

## What changes

- Make member search directly accessible from map and offer results on both
  native platforms.
- Use the web member search filters and the existing policy-protected search
  handler.
- Show meeting availability and volunteering on native offer search cards.
