## Why

Administrators need to inspect hidden profiles and understand their visibility from the member report.

## What Changes

- Allow administrators to load non-public profiles in the existing profile preview.
- Explain known visibility restrictions in the admin member report, using existing account fields.
- Preserve member-facing access restrictions. No migration or deployment changes are required.

## Capabilities

### Modified Capabilities

- `admin-moderation`: Hidden profile inspection and visibility reasons on the member report.

## Impact

The users profile access policy and admin member report change.
