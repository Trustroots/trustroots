## Why

Members need to estimate distances on the map, including walks to and from petrol stations while hitchhiking.

## What Changes

- Show a live metric scale by default on the web, Android and iOS maps.

## Capabilities

### New Capabilities

### Modified Capabilities

- `map-rendering-compatibility`: Show the distance scale across the web and native map renderers.

## Impact

The web search, location and circle maps, Android search map, and iOS search and location maps are affected. The change requires no data migration or new settings.
