## Why

Homepage updates need to reach the NomadWiki relay, and administrators need to be able to feature notes found there.

## What Changes

- Send new homepage notes to the Trustroots and NomadWiki relays and report which relays acknowledged publication.
- Add NomadWiki to the existing relay lookup for homepage curation.

## Capabilities

### Modified Capabilities

- `nostr-integration`: Include NomadWiki when publishing or looking up featured homepage notes.

## Impact

- Nostr admin composer, relay lookup and browser tests.
