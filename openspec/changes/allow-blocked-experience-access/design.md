## Design

Extend the existing minimal reply-recipient endpoint to accept a block by the target as an alternative to an incoming Experience. Include only the viewer's own active Experience, without its reciprocal response. Reuse the profile route and existing Experience and report controls for a limited view; continue to use the normal profile API and its block restrictions for all other profile data.

No data migration is needed. Existing creation, moderation, and publication rules remain authoritative.
